# Sumber Modul

Direktori ini memuat berkas pendukung tiap bab: lembar kerja, templat, data
studi kasus, dan berkas teknis opsional yang dirujuk dari naskah modul. Naskah
bab merujuk berkas di sini dengan penulisan seperti
`sources/chapter02/simulasi-dua-sisi.py`, sehingga mahasiswa dapat memakai
templat yang sama tanpa menyalin ulang dari halaman cetak.

Susunannya satu subdirektori per bab. Tiap subdirektori punya `README.md` berisi
tabel daftar berkas dan kegunaannya. Seluruh contoh Medikara memakai data latihan.
Tarif kerja pada seluruh contoh adalah Rp60.000 per jam, dan angka dasar janji temu
adalah 28.000 per bulan, sesuai Bab 1.
