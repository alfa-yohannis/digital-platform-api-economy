# Sumber Bab 03

Berkas ini mendukung Aktivitas dan Latihan Bab 3 untuk tonggak C1. Salin templat sebelum mengisi. Contoh Medikara memakai data latihan dan bukan bukti organisasi nyata.

| Berkas | Kegunaan |
| --- | --- |
| [peta-ekosistem.md](peta-ekosistem.md) | Lembar kerja tawaran nilai, pelaku, aliran nilai, sambungan terlemah, dan status *boundary resources* |
| [contoh-peta-ekosistem-medikara.csv](contoh-peta-ekosistem-medikara.csv) | Contoh isi peta ekosistem Medikara untuk impor ke *spreadsheet* |
| [matriks-opsi-strategi.md](matriks-opsi-strategi.md) | Lembar kerja biaya, matriks keputusan, uji bobot, dan titik impas tiga opsi strategi |
| [hitung-matriks-opsi.py](hitung-matriks-opsi.py) | Skrip Python untuk skor tertimbang, uji bobot, dan titik impas: `python hitung-matriks-opsi.py` |
| [aturan-keterbukaan-mitra.md](aturan-keterbukaan-mitra.md) | Lembar kerja tangga keterbukaan dan aturan dasar keterbukaan |
| [tingkat-akses-mitra.yaml](tingkat-akses-mitra.yaml) | Contoh tangga keterbukaan dalam bentuk yang dapat dibaca mesin |
| [catatan-keputusan-strategi.md](catatan-keputusan-strategi.md) | Templat catatan keputusan satu halaman beserta contoh terisi |

CSV memakai UTF-8 dan koma. Hapus komentar `#` di baris pertama saat impor ke *spreadsheet*. Periksa satuan angka dan bedakan bukti, asumsi, serta target.

Skrip hanya dipakai pada data sintetis atau sumber berizin. Contoh teknis adalah latihan lokal. Konfigurasi produksi memerlukan tinjauan keamanan dan operasional.
